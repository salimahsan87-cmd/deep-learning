# Deep Learning Projects

A collection of hands-on projects and experiments exploring deep learning, natural language processing, computer vision, reinforcement learning, audio processing, and time-series analysis using Python.

## 📌 Projects

### 1. Audio Classification with CNN
**File:** `CNN_audio-1.ipynb`

An audio-processing project exploring the application of Convolutional Neural Networks (CNNs) to audio-related data.

### 2. Digikala Product Analysis
**File:** `Digikala_Product-1.ipynb`

A data analysis project focused on Digikala product data.

### 3. Persian Sentiment Analysis with LSTM
**File:** `LSTM_Digikala_Comment-1.ipynb`

A natural language processing project exploring LSTM-based deep learning for analyzing Digikala customer comments.

### 4. Reinforcement Learning Experiments
**File:** `My_RL-1.ipynb`

A collection of experiments exploring reinforcement learning concepts and implementations.

### 5. TRX Time-Series Analysis
**File:** `TRX-1.ipynb`

A time-series project focused on TRX cryptocurrency data and deep learning experiments.
